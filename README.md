# 📊 Customer Churn Prediction App

This project is a **Streamlit web application** that predicts customer churn using a **Gaussian Naive Bayes machine learning model**. It allows users to input customer details (Age, Tenure, and Gender) and instantly get a churn prediction.

## 🚀 Features

- Interactive GUI built with **Streamlit**
- Upload or use built-in dataset (`churn_dataset.xlsx`)
- Predict churn using a trained **Gaussian Naive Bayes** model
- User input via sliders and radio buttons
- Model accuracy is displayed in real time
- Dataset preview and summary included

## 🧠 Machine Learning Model

- **Model**: Gaussian Naive Bayes
- **Data**: Custom Excel dataset with customer information
- **Target**: `Churn` (Yes/No)

## 📁 Files Included

- `churn_gui_app.py` – Streamlit app script
- `churn_dataset.xlsx` – Sample dataset for training
- `requirements.txt` – Python dependencies
- `README.md` – Project documentation
